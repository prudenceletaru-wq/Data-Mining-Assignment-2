# DSC8307: Data Mining, Modeling and Analytics – Assignment 2

**Programme:** MSc Data Science and Analytics  
**Course Code:** DSC8307

This repository contains two complete, independent Jupyter Notebooks developed for the project-based assignment. Both notebooks are designed to be executed from beginning to end.

## Repository Contents

- `wholesale_customers.ipynb` – Project 1: Wholesale Customer Segmentation.
- `credit_card_fraud.ipynb` – Project 2: Credit Card Fraud Detection.
- `requirements.txt` – Required Python dependencies.
- `README.md` – Instructions for setting up and running the projects.
- `wholesale-customers.csv` and `creditcard.csv` – Required datasets. These should be placed in the root folder alongside the notebooks.

## How to Run

1. **Install the required dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

2. **Place the datasets** (`wholesale-customers.csv` and `creditcard.csv`) in the same root folder as the notebooks.

3. **Launch Jupyter Notebook or JupyterLab:**

   ```bash
   jupyter notebook
   ```

4. **Run the analysis:** Open either notebook and select **Kernel > Restart & Run All** to execute the complete analysis from beginning to end.
